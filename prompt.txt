Create a file structure for a website for a student organization called the "Thucydides Society for Military History".
This website is simple, with the following pages:
- A home page, containing a welcome message, logo, mission statement, and a preview of the next meeting
- A calendar page, containing a FullCalendar menu displaying all events
- An admin login, and behind it, a UI for adding and modifying events on the calendar
- A resources page, containing an "about us" section, a "learning" section, a "team members" section, and a "contact us" section

The calendar events are held in a supabase database. The website will be hosted on Vercel.
The tech stack is as follows: JavaScript, React, Next.js, Tailwind CSS, FullCalendar, Supabase, Vercel, Git/GitHub, Node.js

Once you have completed all of these things, create a file called "spec.md" which explains the file structure, 
explains what each file does, and contains a section at the bottom called "TO-DO", which explains what the next
step from there is.
